# OTG Barber Studios

Premium barber studio website, built with Vite and prepared for Cloudflare Pages.

## Deploy

1. Add the complete website source and official OTG assets from the project archive to this repository root.
2. In Cloudflare, create a Pages project connected to this GitHub repository.
3. Set build command to `npm run build` and build output directory to `dist`.
4. Use production branch `main`.

Booking: https://otgbarberstudiobooking.setmore.com

The complete source archive is available in the ChatGPT conversation. This README is an initial repository scaffold, not the finished site.
